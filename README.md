# JinxO Online

같은 주제에 대한 세 가지 답을 적고, 서로 통하는 답을 찾아 3×3 빙고를 완성하는 2–7인 실시간 파티 게임입니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 확인은 `npm run build && npm start`로 합니다. 기본 포트는 `3000`이며 `PORT=3001 npm start`처럼 바꿀 수 있습니다.

## 규칙

- 방장은 초대 코드를 공유하고, 2명 이상 모이면 게임을 시작합니다.
- 9라운드 동안 75초 안에 주제에 맞는 서로 다른 답 3개를 제출합니다.
- 공백·대소문자·기본 문장부호를 무시한 완전 일치를 자동 판정합니다.
- 두 명 일치: ★, 세 명 이상 일치: ○, 혼자 낸 답: ×.
- ○는 1점, ★는 2점, ○로 완성한 빙고 줄은 기본 3점 보너스입니다. `BINGO_BONUS` 환경 변수로 바꿀 수 있습니다.

## 검증과 배포

```bash
npm run check
```

`render.yaml`은 Render Web Service용 Blueprint입니다. `main` 브랜치에서 자동 배포되며 `/health`로 상태를 확인합니다. 첫 배포는 단일 인스턴스의 메모리 방 상태를 사용합니다.
