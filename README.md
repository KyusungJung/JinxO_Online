# JinxO Online

같은 주제에 대한 세 가지 답을 적고, 서로 통하는 답을 찾아 3×3 빙고를 완성하는 2–7인 실시간 파티 게임입니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 확인은 `npm run build && npm start`로 합니다. 기본 포트는 `3000`이며 `PORT=3001 npm start`처럼 바꿀 수 있습니다.

## 규칙

- 방장은 초대 코드를 공유하고, 2명 이상 모이면 게임을 시작합니다.
- 주제 카드를 읽은 뒤 모든 플레이어는 75초 안에 서로 다른 답 3개를, 각자 고른 빈 보드 칸에 배치합니다. 답은 최대 두 어절이며 이전 주제에서 사용한 답도 다시 쓸 수 없습니다.
- 이 작성 단계를 **3개 주제**에 대해 반복해 3×3 보드의 9칸을 먼저 모두 채웁니다. 토픽 사이에는 답 공유나 점수 판정을 하지 않습니다.
- 9칸을 모두 채운 뒤 참가자들이 돌아가며 자신의 아직 공개하지 않은 답 하나를 선택해 읽습니다. 답 칸에는 작성 당시의 토픽 번호·토픽명·색상이 남아 있어 어떤 주제의 답인지 확인할 수 있습니다.
- 모든 답을 공유한 뒤 공백·대소문자·기본 문장부호를 무시한 완전 일치를 자동 판정합니다. 두 명 일치: ★, 세 명 이상 일치: ○, 혼자 낸 답: ×.
- ○는 1점, ★는 2점, ○로 완성한 빙고 줄은 기본 3점 보너스입니다. `BINGO_BONUS` 환경 변수로 바꿀 수 있습니다.

## 검증과 배포

```bash
npm run check
```

`render.yaml`은 Render Web Service용 Blueprint입니다. Free 플랜은 비활성 상태 뒤 휴면하므로 첫 요청이 느릴 수 있습니다. `/health`로 상태를 확인하며, 첫 배포는 단일 인스턴스의 메모리 방 상태를 사용합니다.
