# JinxO Online 목표

JinxO를 게스트 초대방 기반의 2~7인 실시간 온라인 빙고 파티 게임으로 만든다. Stitch 프로젝트 `1161748266449457266`의 팝아트 게임 UI를 충실히 반영하고, GitHub `KyusungJung/JinxO_Online`에 푸시한 뒤 Render 프로젝트 `prj-d9s72jqfngtc73en1ch0`에서 동작하게 배포한다.

공동으로 확인한 기능·규칙 기준은 [facts.md](facts.md)에, 구현 순서·아키텍처·검증·열린 결정은 [plan.md](plan.md)에 있다.

완료 조건은 2~7명의 게스트가 초대 코드로 입장해 9라운드 게임을 실시간으로 끝내고, 자동 일치/빙고 점수/결과/재대결을 사용할 수 있으며, 테스트를 통과한 앱이 GitHub main과 Render 배포 URL에서 검증되는 것이다.
